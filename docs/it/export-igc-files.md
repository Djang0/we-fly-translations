## I tuoi voli sono già là fuori: riportiamoli a casa

Registri già i voli su XContest o DHV-XC, o hai anni di tracce ferme sul tuo Syride? Non serve rivolare tutto. Ecco come tirare fuori quei file IGC da dovunque si nascondano e portarli su We-Fly.

---

## Piattaforme online

### XContest

Il più grande libretto di volo libero del mondo. Le tue tracce sono lì. Devi solo andarle a prendere.

1. Accedi su [xcontest.org](https://xcontest.org)
2. Clicca sul tuo nome utente → **My flights**
3. Apri un volo qualsiasi dall’elenco
4. Nella pagina di dettaglio del volo, cerca l’**icona di download** (etichetta «IGC file») vicino alla mappa della traccia
5. Cliccala. Il browser scarica il file `.igc`

Puoi anche scaricare tutto in blocco:
- Vai su [xcontest.org](https://xcontest.org)
- Apri **My flights**
- Seleziona una stagione che contiene già dei voli
- Clicca il link **ALL IGC** (in basso a sinistra)
- Scarica il file ZIP

---

### DHV-XC

Il campionato online nazionale tedesco: registri solidissimi, interfaccia un po’ complicata.

1. Accedi su [dhv-xc.de](https://www.dhv-xc.de)
2. Vai su **My flights** (Meine Flüge)
3. Apri la pagina di dettaglio del volo
4. Trova il **link di download IGC** in fondo alla pagina (spesso con l’etichetta «Download IGC-File»)
5. Fatto, prendi il file

## App per smartphone

### Flyskyhy (iOS)

Il logger di riferimento per i piloti Apple. I tuoi file IGC sono proprio nell’app.

1. Apri Flyskyhy → **Logbook**
2. Tocca il volo che ti interessa
3. Tocca l’**icona di condivisione** (in alto a destra, il quadrato con la freccia)
4. Seleziona **send to XContest** o **Send to DHV-XC**
5. Poi puoi scaricare il file IGC dalla piattaforma.

**Consiglio:** puoi trovare i file IGC anche nell’app File, nella cartella di Flyskyhy, se hai attivato l’accesso a File.

---

### XCTrack (Android)

L’app strumento di volo per parapendio su Android, nonché il sistema che fa girare strumenti come l’AIR³. Le tracce si salvano automaticamente dopo ogni volo.

**Con il widget Share (il più semplice):**
1. Nella schermata principale, tocca il **widget Share** (in alto a destra, sembra un’icona di condivisione/caricamento)
2. Scegli un’app installata: Gmail, WhatsApp, Telegram, Google Drive, ecc.
3. Il file IGC è allegato e in viaggio

**Dal menu Tracklogs:**
1. Apri XCTrack → **Menu** (in alto a sinistra) → **Tracklogs**
2. Tieni premuto sul volo o tocca l’icona del menu a tre puntini
3. Seleziona **Share** → scegli l’app di destinazione
4. Mandalo a te stesso o salvalo direttamente sul telefono

**Con il caricamento automatico su XContest (se è già collegato):**
1. Collega il tuo account XContest in **Menu → Preferences → Pilot**
2. Dopo l’atterraggio, appena hai internet, la traccia viene caricata automaticamente
3. Poi scarica l’IGC da XContest (vedi sopra)

**Via USB (prendi direttamente il file):**
- I file si trovano in `/storage/emulated/0/XCTrack/tracks/` (o sulla scheda SD)
- Collega via USB → attiva la modalità **Trasferimento file** → apri quella cartella → copia i file `.igc`

---

### XCSoar (Kobo / Android / Windows)

XCSoar registra nativamente file IGC. Nessuna conversione necessaria.

1. I voli vengono salvati nella cartella **XCSoar/logs/** del dispositivo
2. Su Kobo: collega via USB → apri `XCSoar/logs/` → copia i file
3. Su Android: stessa cartella, via trasferimento file USB o con un’app di gestione file
4. I file sono nominati per data: `2024-07-15-XCS-XXX-01.igc`

## Strumenti e hardware

### Oudie / Naviter (Oudie N, Omni, Oudie IGC …)

Naviter produce diversi dispositivi: alcuni sono logger dedicati, altri girano su Android. Il percorso di esportazione dipende da quale hai.

**Oudie N / Oudie Omni (basati su Android, con SeeYou Navigator):**

*Dall’app SeeYou Navigator:*
1. Apri **SeeYou Navigator** → tocca **Menu** → **Logbook**
2. Seleziona un volo
3. Tocca l’icona **Upload** → scegli la piattaforma (XContest, DHV-XC, ecc.)
4. Scarica il volo dalla piattaforma scelta.

*Via USB:*
1. Collega via USB → attiva il **Trasferimento file** sul dispositivo
2. Apri `Internal storage/SeeYou Navigator/` (o simile)
3. Copia i file `.igc`

*Da SeeYou Cloud (se la sincronizzazione automatica è attiva):*
1. Accedi su [seeyou.cloud](https://seeyou.cloud)
2. Vai su **Flights** → apri un volo
3. Clicca **Download IGC**

**App SeeYou Navigator (sul tuo telefono Android/iOS):**
- Come per l’Oudie N qui sopra: Logbook → seleziona il volo → invia

---

### Skytraxx (2.1, 4.0, 5.0 …)

Collega e vai. Lo Skytraxx si monta come chiavetta USB: niente driver, niente drammi.

1. Collega lo Skytraxx al computer via USB
2. Compare come unità esterna
3. Apri l’unità → cerca la cartella **IGC** (o i file nella cartella principale)
4. Copia i file `.igc` che ti servono

---

### Syride (serie SYS)

Strumenti francesi, solidissimi. I file si trasferiscono via USB o con il software per computer.

**USB (il modo più veloce):**
1. Collega lo strumento Syride via USB, si monta come unità
2. Apri la cartella **FLIGHTS** sul dispositivo
3. Copia i file `.igc` sul computer

**Da [syride.com](https://syride.com):**
1. Accedi → **My flights**
2. Clicca un volo → **Download IGC**

---

### Flymaster (B1 Nav, Live SD, …)

1. Collega il Flymaster via USB, si monta come unità
2. Apri la cartella **TRACKS** o **FLIGHTS**
3. Copia i tuoi file `.igc`

**Da [flymaster.net](https://flymaster.net):**
1. Accedi → **My flights**
2. Apri un volo → **Download IGC**

---

### SkyBean (SkyDrop, SkyDrop+)

SkyDrop è un logger minuscolo e leggerissimo che registra file IGC.

1. Collega lo SkyDrop al computer via USB
2. Apri la cartella **IGC** o **FLIGHTS**
3. Copia i file

---

## Quando hai i tuoi file IGC

Vai su [/upload](/upload), trascina dentro i file e We-Fly pensa al resto: statistiche, termiche, tutto quanto. Puoi caricare fino a 50 file alla volta se hai un arretrato da smaltire.

Cieli blu e libretti pieni.
